# Решения контестов по C++, осень 2026

В этом репозитории собраны решения прошедших контестов по курсу «C++ Осень 2026».

Каждая директория соответствует отдельному контесту:

- `1-basics` — базовый синтаксис и циклы;
- `2-functions` — функции;
- `3-arrays-and-structs` — массивы и структуры.

Файлы внутри каждой директории названы по номерам задач: например, `1-basics/4.cpp` содержит решение задачи № 4 первого контеста.

## Компиляция и запуск

Из корня репозитория можно скомпилировать и запустить задачу. Например, № 1 первого контеста:

```sh
g++ 1-basics/1.cpp -o /tmp/cpp_fall2026_task1
/tmp/cpp_fall2026_task1
```

Результат:

```text
A simple problem.
```
